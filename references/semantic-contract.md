不要依赖视图筛选、字段顺序或表名中的同步时间。读取全量记录并按字段名解释。

## 一行代表什么

一行代表“某机构与某达人，在某平台、某项目/专项、某一合作批次中的一次合作”。同一达人再次合作必须是不同记录；课程教学可能同达人批量多期，不是天然重复。

跨表稳定键是 `唯一 ID`。业务消歧顺序：发布链接/内容 ID → 唯一 ID → 主页稳定身份 → 昵称 + 平台 + 项目/专项 + 合作时间。

## 当前字段

- 身份：唯一 ID、机构、达人名称、主页链接、抖音号/小红书号、UID、DID、平台。
- 分类：项目/专项、端口、合作形式、达人量级、账号类型、身份、一级行业、二级行业、内容细分。
- 提报：提报时间、提报客户时间、预定档期、选题/备注、提报审核、提报客户反馈、报价、报价截图。
- 执行：进度、脚本、大纲时间、初版脚本时间、终板脚本时间、视频初稿时间、视频终稿时间、预计发布日期。
- 发布：发布时间、发布链接、阅读、赞、评、藏、转发、互动总和。
- 公式：实际合作价、执行天数、时间周期等公式列只核对，不由迁移脚本覆盖。

## 日期语义

- `提报时间`：机构向焦尾提报。
- `提报客户时间`：焦尾向客户提报。
- `预定档期`：提报阶段档期沟通，不是执行 DDL。
- `预计发布日期`：执行阶段的正式预估 DDL。
- `发布时间`：实际发布事实。

## 阶段证据

| 阶段 | 多维表证据 | 需要外部实时核对时 |
|---|---|---|
| 提报 | 提报时间、主页、报价、提报审核 | 客户提审表 |
| 执行 | 进度、脚本、阶段时间、预计发布日期 | 当周执行文档 |
| 审核 | 进度、提报客户反馈 | 客户审核表 |
| 发布 | 发布时间、发布链接、互动数据 | 客户发布表与公开作品页 |

发布事实优先于执行进度，但不能把同名达人的历史发布继承给本次合作。

## 问答粒度

- `记录数`：符合筛选条件的表行数。
- `执行中`：有实际执行进度、且尚未发布/暂停/取消的记录。
- `已发布`：进度为已发布，或已有实际发布时间/发布链接的记录。
- `实际合作数`：需要根据业务问题明确口径，不能无条件等同于记录数。
- 同达人多期课程教学、跨专项或跨机构是合法多记录；只有稳定键和合作批次都冲突时才标记疑似重复。

## 进度

常见顺序：待确认、待执行、大纲、脚本、待开拍/拍摄、视频审核/修改、客户审核、待发布、已发布、暂停、取消。源选项可以更细；统计代码按语义映射，不能改写原值制造不存在的阶段。

## 链接与附件

- 主页、脚本、发布链接读取真实 URL；不要拿显示文本当地址。
- 写入时用普通 URL，显示文本留空，让飞书自动生成标题。
- 附件复制 file_token；无法访问/已删除的源附件保留异常记录，不制造伪链接。
